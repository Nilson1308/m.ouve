# M.Ouve (Ouv.IA)

**Ouvidoria digital** que o cidadão usa como app e a gestão opera como sala de comando

IA na entrada · scatter-gather · indicadores na saída

---

## O problema

- Formulários longos → abandono
- Demanda perdida entre secretarias
- Sem SLA operacional para o ouvidor
- Sem rastro auditável
- Eventos em massa viram caos

---

## Nossa resposta

| Dor | M.Ouve |
|-----|--------|
| Abandono | Chat com IA + coleta dinâmica |
| Silos | Protocolo único + OS por setor |
| Prazo | Kanban, TMA/SLA, alertas |
| Auditoria | Histórico chat + tramitação |
| Massa | Super OS e clusters com IA |

---

## Quem ganha

- **Executivo:** dashboards, mapa GIS, inelegibilidade IA
- **Ouvidor:** mesa Kanban, validação gather, CSAT
- **Secretaria:** painel setorial, OS, magic link
- **Campo:** formalização com fotos
- **Cidadão:** PWA, protocolo, notificações

---

## Pacote Bronze

**Canal digital + Mesa**

- PWA + backoffice Kanban + RBAC básico
- Até **15 serviços**, treinamento 8h remoto
- Referência: **R$ 48k–72k/ano** + setup **R$ 25k–40k**

---

## Pacote Prata *(recomendado)*

**Operação integrada**

- Painel setorial, dashboards, Form Builder, Web Push
- Até **40 serviços**, workshop 16h
- Referência: **R$ 95k–140k/ano** + setup **R$ 55k–85k**

---

## Pacote Ouro

**Governança e expansão**

- Homologação, integrações API, pacote LGPD
- Capacitação ampliada + suporte estendido
- A partir de **R$ 180k/ano** + setup **R$ 100k+**

---

## Por que M.Ouve?

1. Scatter-gather nativo
2. IA conversacional + triagem de inelegibilidade
3. PWA + Web Push (sem app store)
4. Catálogo versionado (Form Builder)
5. RBAC multi-secretaria
6. Manuais e FAQs in-app

---

## Objeções → respostas

- **Já temos 156/ERP** → canal cidadão + orquestração; integra via API
- **IA arriscada** → humano valida gather; auditoria de chat
- **LGPD** → instância dedicada; pacote Ouro com apoio documental
- **Licitação** → documentação e API prontas para anexo técnico

---

## Demo em 15 minutos

1. **PWA:** nova solicitação → protocolo
2. **Notificações** + ajuda ao cidadão
3. **Mesa:** despacho multi-setor
4. **Detalhe 360º** + visão executiva (TMA/SLA)
5. **Fechamento:** piloto 90 dias — pacote Prata

---

## Piloto 90 dias — metas

- ≥ 70% atendimentos via PWA (negociável)
- TMA antes/depois documentado
- ≥ 1 secretaria no painel setorial
- CSAT ≥ 30% dos resolvidos
- Ouvidor autônomo com manual in-app

---

## Próximo passo

1. Escolher pacote e catálogo inicial (**Anexo I**)
2. Proposta + cronograma (4–8 semanas)
3. Kick-off: RBAC, VAPID, treinamento mesa
