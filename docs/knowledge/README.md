# Base de conhecimento — M.Ouve

Esta pasta reúne **guias de negócio, fluxos operacionais, design e arquitetura conceitual**. Serve onboarding, treinamento de servidores e alinhamento de produto.

**Não use estes arquivos como especificação de API.** Para rotas e payloads, consulte [`API_CONTRACT.md`](../../API_CONTRACT.md) na raiz do repositório.

- Form Builder e catálogo dinâmico
- RBAC e governança administrativa
- Mesa de trabalho, painel setorial e visão 360º
- Dashboards gerenciais (conceito e telas)
- Design system, cores e wireframes
- Integração conceitual do chat com IA
